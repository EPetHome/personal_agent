# Codex message-listener 钩子

- **能让它做什么**：无。
- **读取**：仅 Hook stdin 的事件参数，不打开会话、不读 notify、不连网、不等中枢。
- **配置改动**：本机插件 `message-listener@personal-agent-local`，包含 `.codex-plugin/plugin.json` 和 `.agents/plugins/marketplace.json` 市场。通过 `codex plugin marketplace add`、`codex plugin add` 登记，不直接改 `hooks.json` 或挪用 `notify`。所有命令使用显式目标 HOME/CODEX_HOME；用户在真实 Codex 中信任钩子是后续人工操作，本段不替用户信任。
- **安装**：`node code/src/hooks/main.ts install --tool codex --home <绝对目标主目录> --inbox <绝对推送目录> [--command <codex可执行路径>]`。安装前精确备份 `.codex/config.toml` 与 `.codex/plugins/`，生成包位于 `<home>/.message-listener/codex/`，不读 auth 或 sessions。PATH 里的 Codex 不可用时由参数指定正确可执行文件，见[使用说明](../../../使用说明.md)。
- **卸载**：同一入口 `uninstall --tool codex --home <目标主目录>`，移除插件/市场并恢复原字节和登记；保留 `.message-listener-backups/codex.json.removed` 供核对。若安装后另有配置改动（含新增信任状态），拒绝覆盖，须先备份并合并，避免丢掉其他设置。
- **安装失败与恢复**：备份明确记录安装成功、已回滚、恢复未完成等状态；已回滚后清理卸载不再恢复配置，用户后来新增的设置/插件原样保留。状态不明或旧备份缺指纹时拒绝自动恢复，须先备份并人工核对。
- **产出**：`<inbox>/codex.jsonl`，字段为 `tool/event/session_id/cwd/transcript_path/at/detail`。`PermissionRequest` → `waiting_permission`；`Stop` → `turn_end`（最终回复）；`SessionEnd` → `session_end`。
- **失败**：与 CC 共用只追加生产协议；输入无效、目录不可写也退出 0，无错误输出。stdin 最长等待 500 ms，Hook 定义超时 1 秒，不注册任何会修改工具行为的处理器。
