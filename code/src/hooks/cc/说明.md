# Claude Code message-listener 钩子

- **能让它做什么**：无。
- **读取**：仅钩子 stdin 的事件参数（会话号、cwd、原件路径、说明/最终回复）；不打开会话、不读取密钥或账号、不连网、不等待中枢。
- **配置改动**：打包为本机插件 `message-listener@personal-agent-local`；通过 `claude plugin marketplace add`、`claude plugin install --scope user` 登记市场/启用插件，不直接往 `settings.json` 或 `hooks.json` 加钩子。所有命令使用显式目标 HOME 和 CLAUDE_CONFIG_DIR。钩子 `async: true`，超时 1 秒，命令自身始终成功退出。
- **安装**：`node code/src/hooks/main.ts install --tool cc --home <绝对目标主目录> --inbox <绝对推送目录> [--command <claude可执行路径>]`。目标没有默认值；生成包位于 `<home>/.message-listener/cc/`，包含独立 `type: module` 元数据、本机市场、插件清单和 Hook。安装前按原始字节/权限备份 `.claude/settings.json`、`.claude/plugins/`，不读其他工具文件。见[使用说明](../../../使用说明.md)。
- **卸载**：同一入口 `uninstall --tool cc --home <目标主目录>`；先移除插件与市场，再精确恢复安装前配置（连登记一起恢复）、移除自己的安装包。备份保留为 `.message-listener-backups/cc.json.removed`。安装后配置若另有变化，拒绝覆盖，先人工合并；不会自动抹掉其他插件的改动。
- **安装失败与恢复**：备份原子记录安装/回滚状态；已回滚的失败安装后续卸载只清理自己的包、不恢复配置。安装/恢复未完成或旧备份缺指纹时拒绝自动恢复，保护用户后来修改的配置及其他插件登记，详见使用说明。
- **产出**：向 `<inbox>/cc.jsonl` 原子追加一行方案格式事件：`tool/event/session_id/cwd/transcript_path/at/detail`。`Notification(permission_prompt)` → `waiting_permission`；`Stop` → `turn_end`（detail 为最终回复）；`SessionEnd` → `session_end`；`idle_prompt` 忽略。
- **失败**：无效输入/目录不可写/特殊文件等静默跳过，退出 0；stdin 超过 1 MiB 或 500 ms 未结束也退出 0。不读/改已有推送内容；推送仍须中枢按原规则与定时来源严格对账。
