# Claude Code 来源组件

- **读取**：显式配置 `sources.cc` 下的 `.jsonl`，只读打开，不跟随符号链接；推送读取显式 `inboxDir/cc.jsonl`，不安装生产者。
- **配置改动**：不改 Claude Code 的任何配置。
- **安装**：无需插件；在 personal agent 的配置里填目录并运行 `detect`。不接真实目录的本批操作见 [`code/使用说明.md`](../../../使用说明.md)。
- **卸载**：把 `sources.cc` 设为 `null`；如要停用全部推送，把 `inboxDir` 设为 `null`。不改、不移、不删任何会话。
- **产出**：统一 `SessionRecord` 的工具、会话标识、原件路径/SHA-256、项目 `cwd`、开工原文/追加要求、最近步骤、未返回调用、助手收尾/会话结束事实、最后活动时间；状态由 core 判断。本组件不发消息。
- **适配规则**：只把 `origin.kind=human` 的用户文本当作意图；工具结果和非 human 输入不算追加要求。`isSidechain=true` 不单独输出。工具调用按 id 等待相应结果，`end_turn` 且无未返回调用才算本轮答完。
- **失败**：JSONL 损坏或关键结构无法识别，按 Claude Code 来源合并报警，其他来源继续。未识别来源版本不会猜测意图。
- **回去看**：配置中的 `commands.cc` 加 `--resume <sessionId>`；只生成文字，不执行。
