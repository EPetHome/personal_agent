# Claude Code 来源组件

- **读取**：显式配置 `sources.cc` 下的 `.jsonl`，只读逐行读取（不整份 readFile），不跟随符号链接；推送读取显式 `inboxDir/cc.jsonl`，不安装生产者。
- **配置改动**：不改 Claude Code 的任何配置。
- **安装**：无需插件；在 personal agent 的配置里填目录并运行 `detect`。不接真实目录的本批操作见 [`code/使用说明.md`](../../../使用说明.md)。
- **卸载**：把 `sources.cc` 设为 `null`；如要停用全部推送，把 `inboxDir` 设为 `null`。不改、不移、不删任何会话。
- **产出**：统一 `SessionRecord` 的工具、会话标识、原件路径/SHA-256、项目 `cwd`、开工原文/追加要求、最近步骤、未返回调用、助手收尾/会话结束事实、最后活动时间；状态由 core 判断。本组件不发消息。
- **适配规则**：本人输入取 `origin.kind=human`；没有 `origin` 的旧版取文本型且不以 `<` 开头的内容，支持字符串和文本分块。任务通知、工具结果、非 human 输入不算追加要求。`isSidechain=true` 不单独输出。未知元数据/内容块忽略，不校验其时间或无关字段。工具调用按 id 等待相应结果，`end_turn` 且无未返回调用才算本轮答完。
- **跳过/失败**：完整可解析但无身份、无消息（含只有元数据/子代理产物）的文件跳过并计入 `fileStats.skipped`，不算读不了；截断 JSON 等真正损坏仍按文件提醒。正常会话不受单文件故障影响；提醒按来源合并、至多 3 例、正文 <=4 KB。来源目录不可读、真正会话核心整体不可用，或非会话跳过率明显高于健康基线才报来源失明；基线/阈值见[使用说明](../../../使用说明.md)。`ignoreProjectPrefixes` 仍按项目过滤，不改原件。
- **回去看**：配置中的 `commands.cc` 加 `--resume <sessionId>`；只生成文字，不执行。
