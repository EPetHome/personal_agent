# Claude Code 旧格式组件

- 检测不再扫描 CC 会话或 hook，不发聊天卡、不调模型，不因 CC 目录不可读报警。
- `index.ts` 的纯解析器仅保留旧格式兼容和构造回归，不是运行中的来源接入。
- `sources.cc` 只在用户明确确认旧卡片转达时使用，由 `core/cc-relay.ts` 安全定位；不会定时读取。
- [message-listener 钩子](../../hooks/cc/说明.md)保留生产/装卸，不自动改现有安装；收到的推送不进入判断。
- 旧会话、事件、发件一个不删、不迁移。转达默认关闭，详见[使用说明](../../../使用说明.md#im-原话转达cc--会话闲着默认关闭)。
