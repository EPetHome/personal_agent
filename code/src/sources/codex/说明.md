# Codex 来源组件

- **能让它做什么**：无。

- **读取**：显式 `sources.codex` 下的 `.jsonl`，及显式 `inboxDir/codex.jsonl`；只读逐行读取、完整 SHA 覆盖原件，不把整个大文件读进字符串；不跟随来源符号链接，不跟随推送的 `transcript_path` 去打开未配置文件。
- **配置改动**：不改 Codex 配置、钩子或 `notify`。
- **安装**：无需 Codex 插件；在 personal agent 配置中填写目录和 `commands.codex`（可执行文件路径，不是带参数的命令串），运行 `detect`。本批只配样本，见[使用说明](../../../使用说明.md)。
- **卸载**：`sources.codex=null`；如停用全部推送再设 `inboxDir=null`。原件原样保留。
- **产出**：统一记录中的工具、会话标识、原件路径/SHA-256、`session_meta.cwd` 起始项目、按原件保留的结构化目录历史（仅供推送对账）、意图、最近步骤、未返回调用、完成/结束事实、最后活动时间。子代理的路径、活动和工具调用并入父会话，不把派给子代理的任务当作用户追加要求。
- **适配规则**：本人输入优先取 `item_completed` 的 `UserMessage`（支持 `event_msg` 包裹和顶层形式），兼容旧 `event_msg/user_message`；两代同时存在不重复记，`response_item` 用户副本不取。真人判空先剥离已知 IDE/系统注入块；纯标签不参与 `hasNewUsers` 代际选择，也不重开完成状态，不能遮蔽旧 `user_message` 里的真实要求。标签后正文和真实图片/附件输入仍有效；顶层 `image` / `input_image` 块即使没有文本占位，也能作为真人新输入、重开本轮；但新版只有图片而无文字时，不据此遮蔽兼容旧格式的文字意图。只检查图片块类型、不读取或保存载荷；系统/非 human 元数据拒绝优先。媒体占位仅在意图提取时去除，不据此判输入为空。清理后仍以 `<` 开头的环境/系统输入和明确标记的 loop/通知都不算本人要求。核心动作包括调用/对应输出及 `CommandExecution`、`FileChange`、`McpToolCall`；只取动作摘要，不复制输出/差异。用 `task_complete`、`turn_aborted` 和推送判断结束；`commentary` 不算收尾。原始调用自身 `status=completed` 不代表 output 已返回，仍按 `call_id` 配对；新完成工具项也不能清掉其他未返回调用。未知顶层/事件/响应/完成项及无关字段一律忽略。
- **子代理**：支持 `session_meta.parent_session_id` 或 `source.subagent.thread_spawn.parent_thread_id`；找不到父会话或关系成环只计这一份文件不可用，不编造父任务；其他正常根会话不失明。父记录保留各成员独立的会话 ID、项目、原件、活动时间与工具事实。推送先按实际成员对账，再归到根父记录判断：子成员等待会让父记录显示「在等我」，回看命令定位实际等待的成员；父/兄弟的新动静不解除它的等待，子成员结束不会误结束父成员或其他会话。子成员首次读取就损坏时，仍可可靠提取的 `session_meta` 身份只用于与可读根任务建立不可用关联；不解析损坏正文前缀来判断调用/完成，也不用于新推送对账。无历史活动事实时成员时间为 `null`；有历史则保留最后事实和父任务关联，并标本轮不可读。该聚合任务不能据此判全部完成，先前已对账的等待也不能自动解除。读恢复后用新事实更新，其他根会话不受影响。
- **推送信任边界**：收到原始推送不等于对账通过。只有追加过明确 `push_validated` 结果的推送参与判断；匹配成员自己的原件，不只检查父记录的聚合路径。读取（含所在目录）或归并失败的原件，其推送只留原始事实、不借缓存成员对账；身份/路径冲突仍立即报对账异常；同号同路径换目录与空会话规则统一见[使用说明](../../../使用说明.md)。旧日志中未经校验的推送不会因故障恢复自动生效，参见使用说明的兼容与备份步骤。
- **跳过/失败**：完整 JSONL 只有 `session_meta`/噪音、没有核心消息，或没有可用身份时，是非会话，跳过并计数，不算文件失败；坏 JSON 不能因缺字段被伪装成空会话。过去已知的未完成子成员后来只剩元数据，也不能被当作已结束或给新推送对账。坏文件提醒仍按来源合并、至多 3 例、正文 <=4 KB；正常根不受影响。目录不可读、真正核心整体不可用或跳过率明显高于健康基线才失明；判定见[使用说明](../../../使用说明.md)。`ignoreProjectPrefixes` 忽略父项目时连同多层子代理排除，不误报孤儿。
- **后台收尾**：`task_complete` 之后落盘的已完成后台 `item_completed` 不重开本轮；新的本人输入、`task_started`、新调用或运行中的工具项仍会重开。
- **推送生产者**：独立的 [message-listener 插件](../../hooks/codex/说明.md)。
- **回去看**：`<commands.codex> resume <sessionId>`，路径有空格时自动 shell 引用；从不启动 Codex。
