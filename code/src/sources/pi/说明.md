# Pi 来源组件

- **读取**：显式 `sources.pi` 下的 `.jsonl`，及显式 `inboxDir/pi.jsonl`。只读，不跟随符号链接，不打开推送中另指的文件。
- **配置改动**：不改 Pi 配置，不装扩展或权限钩子。
- **安装**：无需 Pi 插件；在 personal agent 配置中填目录，运行 `detect`，见[使用说明](../../../使用说明.md)。
- **卸载**：`sources.pi=null`；如停用全部推送再设 `inboxDir=null`，不动会话。
- **产出**：统一记录中的工具、会话标识、原件路径/SHA-256、首行 `cwd` 项目、当前分支的开工原文/追加要求、最近步骤、未返回调用、助手收尾事实和最后活动时间。
- **适配规则**：支持 v2/v3 树形 JSONL；从最后写入节点沿 `parentId` 走到根，只读当前分支，不平铺废弃分支。用户意图来自 `message.role=user`，排除已标记的系统输入；`custom_message`、`custom`、`branch_summary`、`compaction` 等都不是用户要求。保留压缩前同一分支上的用户原文，不用压缩摘要代替本人指令。工具调用和 `toolResult` 按 id 配对；`stopReason=stop` 且无未返回调用可判本轮答完。
- **失败/限制**：断链、成环、重复节点、未知版本报失明；旧 v1 需另做只读适配，本组件不调用 Pi 自动迁移。尚未写入文件的纯 `/tree` 导航无法从 JSONL 观察；按最后持久化节点判断，下一次写入后更新。
- **格式参考**：Pi 安装文档 `docs/session-format.md`、`docs/message-types.md`；没有引入 Pi SDK 运行依赖。
- **回去看**：`<commands.pi> --session <sessionId>`，只生成命令文字。
