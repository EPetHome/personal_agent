# file 文件渠道

- `detect` 保留的文件出口，只向显式数据目录 `outbox.jsonl` 追加提醒，不联网、不操作来源工具。
- 当前新发仅 loop 卡与 PA 故障。旧聊天卡/日报/周报/复盘仍可读取和反馈，但不再补发或重试。
- 决策先记 `events.jsonl`，文件交付按提醒id幂等，之后记确认；未确认时显示待写，不用文件成功冒充外部渠道成功。loop按状态证据、健康按故障期去重；误报同批次同原因后不投递。
- 发件核对用独立短锁，反馈独立短锁保存原卡/原话/时间，不等模型/API/检测。既有事件、发件与反馈不重写、不删除。
- 结构化content、给人看的text、回看定位仍保留；不执行回看命令。具体接口、数据与恢复见[使用说明](../../../使用说明.md)。
