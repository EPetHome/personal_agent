# file 假渠道

- **读取**：显式数据目录中的 `outbox.jsonl`，核对已经交付的提醒编号；不读任何工具配置或账号。
- **配置改动**：不改任何外部配置。
- **安装**：无需额外软件或配置；本批 `detect` 唯一使用的渠道，数据目录必须显式给定。见[使用说明](../../../使用说明.md)。
- **卸载**：停止运行检测即可；不自动删除任何事件或发件事实，亦不需要卸钩子。
- **产出**：只向 `outbox.jsonl` 追加提醒（内部 `id`、去重键、时间、工具、级别、类型、结构化 `content`、给人看的 `text`）。`text` 不含内部提醒编号/会话关联键；回看命令中的原工具会话 id 和证据中的原件路径是必要定位信息，不是提醒编号。
- **可靠性**：决策先追加到 `events.jsonl`，投递按提醒编号幂等，写入成功后再追加交付确认事件；没有确认时总览标为「待写发件记录」，不把计划发送冒充已发。中断后下一轮补齐并确认。停滞每会话一次；等待按推送事实、loop 按状态证据、失明按连续故障期去重。
- **边界**：不执行回看命令、不通知 macOS、不发飞书、不连网、不收回复。`feedback.jsonl` 只初始化为空，反馈留后续批次。
