# local 本机渠道

- 仅处理传入 `Notice`，不读聊天目录或工具配置；只有显式 `localChannel.executable` 才运行通知程序，开发/门禁必须用替身。
- 当前新卡仅 loop 与 PA 故障；紧急级本机+飞书，有空看不弹本机。loop 暂停仍等五分钟，loop 看不见当轮叫；不再生成聊天等待/跑偏/停滞或定时报告。
- 固定AppleScript通过argv传标题/摘要，不使用shell或执行回看命令。第一屏保留事情、首件动作与总件数、当地时间、回看；完整证据留在发件。
- 反馈独立 `.feedback.lock` 落盘，正确/误报/漏了/看不懂及旧卡关联不变；反馈只保存，不再生成问题汇总或复盘。未知活锁不清理。
- 发件和本机交付分别留痕；连续失败5次停发并尝试一次本机告知，磁盘满直接告警且不递归。外部通知与本地确认没有事务，不能保证绝不重复。
- 配置、假渠道与恢复见[使用说明](../../../使用说明.md)。本批不弹真实通知、不改系统权限。
