- 信任边界：`agent` 的新对账及事件重放中的 `push_validated` 检查都要求成员本轮可读；不可用成员/只有身份的成员不能授权新推送。历史已经验证的等待仍可定位缓存事实，不被新结束推送自动解除。空、缺失、非字符串或成环的父标识不能编造父任务。
- 验证：首次只有元数据、元数据加未返回调用、元数据加完成前缀后三种末行损坏场景，均保留不可用关联、不假完成/假等待；无关根仍已完成。重复检测只增加一个检测时间事件，查询/删除状态后重建一致，恢复完整读取后正常完成。另覆盖既有授权等待再损坏、多层失败身份关联、无效/无父/成环身份，以及不可用成员无法产生新验证（含直接校验和重放拒绝）。数据文件逐行 JSON 解析通过。
