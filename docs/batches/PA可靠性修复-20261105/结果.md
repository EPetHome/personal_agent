### 实施

1. **图文与图片类型**：`channel.ts/image.ts` 提取 post 标题/正文与 img 节点，content/content_v2 作为替代表达而非重复消息；图片按 key 去重，独立 image/file、本人/私聊过滤与按钮/引用路径保留。PNG 校验块边界/CRC，JPEG 校验标记/尺寸/结束结构，GIF/WebP 按内容识别；后缀、附件 MIME、模型 image MIME 不再固定 PNG。不识别/不完整时说明原因。原名与接收记录持久化；纠正已登记旧路径时保留受检本地别名，重启引用仍可用。附件目录被替换成外指链接时拒绝，不把它当新读写授权。
2. **文件与能力事实**：`list_directory` 复用受限文件边界；主助手/Pi 共享文件策略、原附件名拒读和正文解析。权限先于文件类型检查，返回稳定的目录/不存在/越界/黑名单等类别；范围外存在/不存在不能用于探测正文或存在性。读取根采用已加载快照，配置文件变化不热加载。`capabilities.ts` 每轮从实际配置、工具注册及 `loopScope` 生成事实，含收件箱、附件、证据登记、Pi 写目录/技能、最终 Loop 禁区、两类感知盲区；不带凭据路径/值，不把 Loop 与普通 Pi 写目录混同。
3. **错误与配置故障**：`SafeError/failure` 只传播明确构造的安全说明；router 包装、worker 执行前核对及记录不再抹掉已知原因，未知异常仍标未知，取消继续传递。启动配置校验未知字段，明确指出 `pi.readPaths` 不生效，项目外 Pi 写目录仍拒绝。看门狗独立加载通知必需字段，业务配置错误时不加载旧权限、仍可报告；通知配置无效时保留明确本机失败信息，不宣称飞书已报警。
4. **文档正文**：`documents.ts/document-worker.ts` 只读提取 UTF-8、DOCX 段落/表格及 PDF 文本层页序。DOCX 只解压选定 XML、核对 ZIP CRC/大小与禁 DTD；PDF 使用 pdfjs，禁动态求值，不使用通用命令/OCR/解密。源文件 20 MiB（还受配置收窄）、正文 2 MiB、单次 64000 字节、100 页、10 秒、worker 堆上限；DOCX 单成员 8 MiB、声明总量 32 MiB/512 项。返回截断与继续位置，UTF-8 不制造半字乱码。扫描件、损坏、加密标志、旧 DOC、XLSX/普通 ZIP、改名二进制及超限有明确失败，不写 TXT、不覆盖原件。
5. **本次确认与不催**：真实本人当前输入 ID/完整正文作为确认来源，与任务、请求和权限快照绑定在既有 worker 执行账；模型不能用一个授权布尔值放行。附件/引用/worker、无明确委托、红线/额外能力仍不能借此执行。保留重复输入/指令只执行一次、取消/定义变化作废、执行前重核、不确定结果不换编号重发。仅缺项目时可持久记录原指令，收到本人项目答复后只补项目，不能借机改目标/范围。旧待定卡在无关问答中不重复提请/发卡，显式关联旧任务的催办回复也拒发；原待办可查询，本人重新交代同一任务可作废旧提请、在原卡按新指令处理。未改永久 approval 开关，派出仍更新既有原卡，不新增专用卡/停止按钮。
