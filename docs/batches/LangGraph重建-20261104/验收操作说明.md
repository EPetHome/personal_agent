# 验收操作说明（LangGraph 重建）

给验收方看。被测系统是新版 PA，代码在开发空间的 `code/agent/`。

## 先读

- `code/agent/使用说明.md`：开发方写的启动、停止、配置、替身用法。具体命令以它为准，本文件不重复。

## 必须遵守

- **只用构造的数据和临时目录。** 数据目录、附件目录、收件箱、授权项目、配置文件都放在系统临时目录下新建的目录里；不要使用、读取或修改 `~/.personal-agent/`、`~/.personal-agent-v2/`、`~/.personal-agent-附件/` 的真实内容。
- **不碰真实账号。** 飞书一律用假飞书替身；Loop 一律用 Loop 替身，不调用真实的 `bin/loop`；不在真实 `~/Library/LaunchAgents` 安装或加载任何东西，需要「挂了自动拉起」时用使用说明里的拉起替身。
- **不碰真实秘密。** 需要 `.ssh/id_rsa` 这类文件时，在临时目录里构造一个假的（内容写成明显的假值），不要读取真实的 `~/.ssh`。
- **Pi 用法。** 标准写了「真实 Pi」的条目，用本机的 `pi`，但用 `PI_CODING_AGENT_DIR` 指向临时配置目录，模型指向使用说明里的脚本模型替身；不要修改 `~/.pi/agent/` 下的任何文件。其余条目用 Pi 替身。
- **模型。** 标了 [授权] 的条目用真实模型（opencode-go 的 `deepseek-v4.1-flash`，密钥由 PA 从 Pi 配置里读，验收方不要读取或打印密钥）；没标 [授权] 的条目一律用脚本模型替身，不产生费用。
- **时限。** 标准里写了具体时长（例如「2 分钟内」「运行 5 分钟」）的，按标准时长；没写的可以按使用说明把看门狗等时限配短以节省时间。
- **收尾。** 每条做完停掉本条启动的 PA、看门狗、替身和 Pi 进程，确认没有残留；临时目录可以保留作证据。
