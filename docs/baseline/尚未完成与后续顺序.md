```
闭环 1 AI 工作盯防（开发已交付，一周试用中，约到 11-02 满一周）
│
├─ ② 减负与封存（一条流水线串行）

├─ ③ IM 转达第一格：CC × 会话闲着（护栏 + 总开关 + 送达 + 输入框）
│     前提：摸底剩两件（Codex 实跑、怎么判断会话正忙）+ 用户配合看一次 VSCode 窗口 + 方案定稿
├─ ④ Pi 转达（先补授权关）→ Codex 转达
│
└─ 收口：A10 一周试用通过；A2 用真实记录核销、A8 重启电脑、A12 卸载钩子
      → 按需求书，闭环 1 用过之后再定闭环 2–6 的顺序；用户 2026-10-28 的「简单的替我处理」（代答）属闭环 3，到时一起拍板
```
