# 需求书：personal agent

资料核对：2026-11-01。状态：**已定稿**（2026-10-24）；底座选型和各项细则留到方案阶段。2026-11-01 起进入第二阶段，需求调整中（D34）。2026-11-02 起架构以[架构重画需求书](需求书-personal-agent-架构重画.md)为准（D39）。

## 一句话

一个跑在我本机后台、没有界面的个人 agent：知道我在忙什么、我的习惯和人际关系，从每天的杂乱输入里找出该做的事，调用我已有的工具去做，再通过本机通知、飞书、微信把结果告诉我。

## 为什么做

- 给谁用：我自己（产品经理）。不为功利，是真心想要一个工具，一个「第二大脑」。
- 核心痛点（来源：核心需求追问，2026-10-24）：很多 AI 同时替我干活，我成了它们之间的人肉调度员。
  1. 盯：要看 AI 做完没有，没有我操作它就一直等着；还要看它做得对不对。如果只能拿走一件事，我最想拿走「盯着」。
  2. 编排：先做哪件、切回来时得重新想起做到哪了、一堆待办放不下，这三样都有。
  3. 读：不想读，又怕 AI 的输出有问题，读得头昏脑胀。
  4. 跑偏：任务做了一段才发现偏离我的诉求，只能推倒重来；有时是我的需求没说清。
- 次要痛点：输入杂（文档、截图、会议记录、杂事）；工具散（loop、LLM Wiki、skill 各管一段）。
- 成功的样子：它每天替我盯着、替我交代，我能专注在主线上。
