## 目标

闭环 1 已在用户电脑上运行，但只做到了「发消息 + 记反馈」：反馈只进统计和复盘，提醒判断完全不用它，用户点了「误报」下次照样被叫；对卡片本身的不满（看不懂、太挤）没有入口，只能由用户截图转述；卡片靠规则从对话原文里抠字，经常说不清「这件事是什么」，几段话挤在一起。用户的评价是「相当于做了一个无限发消息的工具」。本批补齐需求：反馈要生效并告诉用户变了什么；personal agent 自己收集对它自己的不满；卡片先说这件事是什么、再说要用户做什么，并且好读。

## 已拍板

- **误报只管同一会话同一原因**（用户 2026-10-27 定）：马上生效。跨会话的规则调整不在本批，以后放进每周小结做建议，用户同意才生效。
- **新卡片格式**（用户 2026-10-27 定），第一屏从上到下：
  1. 标题：谁 + 出了什么事，一句话（如「shop 的 Claude Code 在等你回复」）
  2. **这件事**：一句话说清这个会话正在做的事和卡在哪里（如「给商品列表加缓存：接口层已改完，卡在旧缓存怎么处理」）
  3. **要你做**：一句话，要回答的问题或要做的动作；不用管就直说「不用管，只是告诉你」
  4. **时间、回去看**：本机当地口语时间；能直接打开那个会话的命令，loop 给总结文件
  5. 按钮：正确、误报、看不懂（每周小结、复盘没有正确 / 误报，但有看不懂）
  6. 证据：默认收起，放原文、判断依据、内部路径
  - 第 2、3、4 项各自成块、段名醒目、块与块之间留空，每块不超过两行；超出的收进证据。不出现截图占位、编辑器 / 系统自动附带的标签、UTC 的 ISO 时间、本程序数据文件路径和行号。
  - loop 交代卡片同样结构：这件事写项目、批次和结论；要你做写还欠几项、要不要管；验收标准原文和欠项明细只放证据。
  - 本机通知用同样的措辞（这件事 + 要你做）。
- **「这件事」「要你做」由判断模型顺带写**（用户 2026-10-27 定）：判断「在不在等你」「是否跑偏」时模型已经读过上下文，让它同时给出这两句。模型不可用、超时或给不出时，用规则兜底：跳过截图 / 附件占位和编辑器 / 系统注入的标签块，只用用户自己打的字和助手最后的问题；兜底也要符合上面的格式。不额外增加模型调用次数。
- **反馈数据只追加**：不改写、不删除已有的收件、处理记录、反馈、经验、事件和发件记录；旧记录缺新字段照常读。新增问题记录如果另存文件，写清升级和回退办法。
- 每日模型调用上限、提醒分级、首次接入不补发、复盘首次不翻旧账、反馈不等检测锁，保持不变。

## 边界

- 只改 `code/` 和本批结果 `docs/batches/反馈闭环与卡片-20261027/结果.md`。不新增第三方运行依赖。
- 不读写真实的 `~/.claude`、`~/.codex`、`~/.pi`、`~/.pi-autoreview`、`~/.personal-agent`；不连真实飞书，不调用真实模型，不弹真实通知。用构造的会话样本、飞书事件和替身。需要真机形态时，按问题单里记下的原文构造（长会话首句「合入。」、截图开头、`<ide_opened_file>` 标签开头、以列表结尾的提问）。已有场景样本目录（`docs/batches/*/samples/`）只读。

- 不做：跨会话的规则自动调整；替用户回复 AI、启动或停止 AI；改检测主流程的加锁方式；钩子安装与卸载。

## 验收标准

A1. 操作：对某会话的「在等你」提醒点「误报」；之后让这个会话因同样原因再停下来，跑一轮检测
    预期：回话写明效果；这次没有新提醒；总览里这个会话标「因你的误报没提醒」
A2. 操作：同 A1 之后，让另一个会话停下来等你，跑一轮检测
    预期：照常提醒
A3. 操作：在一张卡片上点「看不懂」，再对另一张卡片引用回复文字「看不懂 太挤了」
    预期：问题记录多两条，各带原卡片和原话；两次都回话确认
A4. 操作：一周内产生 3 次「看不懂」、2 次「误报」、5 次「正确」，生成每周小结
    预期：小结里「看不懂 3 次」「误报 2 次」分开列出；「正确」不出现在问题和复盘里，也没有推复盘卡片
A5. 操作：放入一份长会话样本：第一句用户话是「合入。」，最近在讨论缓存方案，助手最后问用户一个问题；判断器替身答「是」并给出「这件事」「要你做」各一句；跑一轮检测
    预期：卡片「这件事」「要你做」是替身给的两句；正文没有「合入。」当意图，没有占位符和编辑器标签
A6. 操作：同 A5，但第一条用户消息以 `<ide_opened_file>` 标签开头，且判断器不可用
    预期：卡片仍有「这件事」「要你做」两块（规则兜底），正文没有占位符和编辑器标签
A7. 操作：查看任意一张「在等你」提醒卡片
    预期：「这件事」「要你做」「时间 / 回去看」是分开的块，每块不超过两行；原文和判断依据只在证据里
A8. 操作：拿一份旧版产生的数据目录（里面已有发过的「在等你」提醒和模型判断记录），用新版跑一轮检测
    预期：不新增提醒，不新增模型调用
A9. 操作：产生一张 loop 交代卡片（还欠 3 项）
    预期：「这件事」写项目、批次和结论；「要你做」写还欠几项；验收标准原文不在第一屏
A10. [人工] 操作：上真机用几天
    预期：卡片一眼看懂；点过误报的事不再来烦你；「看不懂」能在周报里看到归并
