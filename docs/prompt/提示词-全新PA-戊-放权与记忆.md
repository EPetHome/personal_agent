# 全新 PA 戊：放权和记忆

本批共 6 段，这是第 5 段，接在「丁 飞书和派活」之后（和「己」互不依赖）。先读[六段共同约定](../batches/全新PA-20261102/共同约定.md)。

## 目标

用户常按建议的那类开始提示改自动；规则、人物要用户确认才进记忆。对应[方案](方案-全新PA.md)第 8、9 项，需求书 7.7。

1. **档位**：按「来源 × 动作」分别计：影子、建议、自动，默认建议。某一类够了线，卡片提示「这类可以改自动」，用户点了才改。自动处理的事后在原卡写明「已按建议处理」，带 [撤回]。被撤回一次或出一次严重错误就退回上一档。派活同样可以改自动。
2. **红线永远不自动**：命中红线的，同类即使已设为自动，照样发卡等用户确认。
3. **规则参照**：从用户的一贯选法起草候选卡，用户一键确认才进，带版本；研判出建议时引用已确认的规则。没确认的候选不进记忆、不被引用。
4. **人、偏好、在忙什么**：同样候选加确认；确认后问答和研判能用上，没确认的不用。

## 已拍板

- 提示线：同一类样本至少 20 条、和用户一致至少 9/10、严重错误 0 次。
- 只有能撤回、或者错了用户能及时发现的，才进自动。
- 意图卡不自动变成规则，观测里的结论也不自动写进任何长期数据，都要用户确认。

## 边界

- 档位和记忆存在账本里（围栏配置和全局记忆两类，见需求书第六节），改档位留痕。
- 不改红线清单本身；改红线清单是红线，只有用户能改。

## 验收标准

A1. 操作：同一类「暂停：环境类 → 继续」攒够 20 条，用户按建议的有 18 条以上，没有严重错误
    预期：收到一张「这类可以改自动」的提示卡
A2. 操作：把这类设为自动，替身再写一条同类暂停
    预期：不打扰用户，PA 直接送「继续」；原卡写「已按建议处理」，带 [撤回]
A3. 操作：点 A2 卡上的 [撤回]，替身再写一条同类暂停
    预期：这类退回建议档，照常发卡等用户点
A4. 操作：替身写一条含红线的「需要你决定」，同类已设为自动
    预期：照样发卡等用户确认
A5. 操作：把某一类派工设为自动，发一条这类任务
    预期：直接派，事后收到「已自动派」卡，带 [撤回]
A6. 操作：同一类「需要你决定」，连续 5 次用户都选同一个选项
    预期：收到一张规则候选卡；点确认后，下一次同类问题的建议里引用这条规则
A7. 操作：不理规则候选卡，再来一次同类问题
    预期：建议里不引用这条候选
A8. 操作：确认一张人物候选卡「张三：Promate 的产品负责人」，再在飞书问「张三相关的事」
    预期：回复列出账本里和 Promate 有关、提到张三的事
A9. 操作：不确认人物候选卡，再问同样的问题
    预期：回复里没有用到这条未确认的信息
