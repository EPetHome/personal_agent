需求、边界、架构图、红线、读的范围、点头表都以[需求书-PA-LangGraph重建](../requirements/需求书-PA-LangGraph重建.md)为准，本文件不重复，只写怎么落地、分几段、验收标准。

## 一、分段

一批三段，按顺序做；甲做完就能先试聊天。

| 段 | 做什么 | 对应需求书 |
|---|---|---|
| 甲 · 能聊能查 | IM 层（只认本人、附件存放）、订阅匹配骨架、输入队列、Router（上下文拼接、回复、查 Loop 状态、读证据和文件）、任务表、读的范围（白名单 + 黑名单底线 + 真实路径）、留痕、收件箱接收、进程启停、看门狗 | 第三、五、六、八、九节 |
| 乙 · 派给 Loop | worker 接口七个动作、Loop 适配、点头暂停与继续、点头过期重核、同一点头只执行一次、核实后才叫你、证据路径限定、做完 / 没全过 / 卡住三类卡片 | 第四、五、七、八节 |
| 丙 · 派给 Pi | Pi 适配、Pi 扩展在工具调用前检查读写、跑命令和联网的开关、并发上限、超时、PA 重启后接着收 Pi 结果、开关关掉后直接做并在原卡写明 | 第五、七、八、九节 |

## 二、技术落地

| 项 | 做法 |
|---|---|
| 位置 | `code/agent/`，独立 package；旧代码 `code/src/` 不动 |
| 语言与框架 | TypeScript，LangGraph.js：`createAgent` + `humanInTheLoopMiddleware`（按工具配「要不要先问」）+ SQLite 检查点 |
| 模型 | OpenAI 兼容客户端，地址 `https://opencode.ai/inference/go/openai/v1`，模型 `deepseek-v4.1-flash`；密钥运行时从 `~/.pi/agent/auth.json` 的 `opencode-go` 项读，不复制、不进日志 |
| 数据目录 | `~/.personal-agent-v2/` 🔧，和旧 PA 分开；在不许读名单里 |
| 附件目录 | `~/.personal-agent-附件/` 🔧，在数据目录之外，列进读白名单 |
| 配置 | 授权项目和目录、读白名单、不许读名单、点头开关、并发和时限都在一份配置文件里；PA 只读不写 |
| 搬旧代码 | 飞书收发和卡片、调 loop 命令、Pi 运行器、launchd 安装；只搬用得上的部分，旧账本和关键词路由不搬 |
| Pi 读写检查 | 写一个 Pi 扩展（参照 Loop 已在用的权限扩展加载方式），在 Pi 调读、搜、列目录、写、改之前按白名单、黑名单、派工范围检查；只读派工不加载跑命令的工具 |
| 执行前重核和只执行一次 | 放在 worker 接口这一层：执行前按派工编号去重，再核对卡片上记下的点头依据（状态、活有没有取消、批次有没有自己恢复）；不靠中间件或模型 |
| 数字 | 对话窗口 100K token，满了丢到约 60K；单次模型调用 60 秒；一条输入 5 分钟；Pi 派工 20 分钟；你的话超过 10 秒没回先回「在处理」；看门狗：心跳 2 分钟、输入卡住 5 分钟、模型连续失败 3 次、飞书断开 5 分钟、磁盘低于 1 GB；全部可配 |

## 三、开工前先验证（甲段第一步）

- **模型兼容**：该模型要求多轮工具调用时把 `reasoning_content` 带回接口（Pi 配置里的 `requiresReasoningContentOnAssistantMessages`），LangChain 的 OpenAI 兼容客户端未必会带。先做最小验证：连续 3 轮工具调用不报错。不行就关思考模式或换 DeepSeek 专用客户端；仍不行就停下报告，不换模型。
- **Pi 扩展能不能在工具调用前拦截**：先用一个构造的只读派工验证；拦不住就停下报告，不退回「只靠提示词」。
- **飞书**：开发和验收只用假飞书；新旧 PA 不能同时连同一个机器人，真飞书留给你最后走一遍。

## 四、验收标准（草稿）

按 Loop 流水线写法：三段共用**一份整批验收标准**（开工时放进批次目录，由 `批次.json` 的 `acceptance.criteria` 指向），编号在整批内唯一，每条开头标归属段，没通过的条目按段名退回那一段修。三段各自的提示词不再另写验收标准，只写明「本段对应整批标准里标 [甲]/[乙]/[丙] 的条目」。

- 带 [授权] 的要调用真实模型（opencode-go，会产生少量费用）。同意授权由你亲手写进这份标准文件；标准一改，旧授权全部失效。
- 飞书、Loop 一律用替身；A21、A22 用真实 Pi 加载读写检查扩展，Pi 的模型换成按脚本发工具调用的本地替身（不花钱，也避免真实模型自己拒绝而测不到拦截）；其余 Pi 用替身。数据全是构造的，不碰真实账号和文件。
- 点头开关除特别写明外都按默认（要问）。真飞书走一遍（需求书第十二节）是业务验收，不在这里。
- 共 26 条，超过 Loop 写法建议的「最多 10 条」（程序不强制，只是写法建议）；整批验收时限要相应放宽，在 `批次.json` 里配。

标准全文只放在 [docs/batches/LangGraph重建-20261104/整批验收标准.md](../batches/LangGraph重建-20261104/整批验收标准.md)（26 条，A1–A10 属甲、A11–A20 属乙、A21–A26 属丙），本文件不再重复。
