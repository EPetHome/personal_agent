# 提示词：减负与封存 · 甲段 提醒与卡片（闭环 1 修复）

依据：需求书 `docs/requirements/需求书-personal-agent.md`「什么时候叫我」2026-10-28 新增一句、D33；问题单（真机事实与回放数据，先读）[我正在电脑前和 AI 来回聊，它还每轮提醒我](../../iusses/在电脑前操作时还在提醒.md)；方案 [IM 转达会话](方案-IM转达会话.md) 第 4 节（本段只做其中「逐件标签、建议、分区」，不做输入框）。

## 目标

用户人在电脑前、正和 AI 来回聊时，不再每轮收到「在等你」；真推到飞书的，只剩用户离开时的。卡片的「要你做」逐件列清楚，分出哪些要回复会话、哪些要用户去别处做、哪些是红线，为以后在 IM 里回复会话打底。

现在：AI 一答完，钩子报回合结束，下一轮检测就调模型判断、立即发卡（`code/src/core/judge.ts` 的 `model_waiting` 分支，去重键按证据时间，每轮回复都是新卡）；渠道只按提醒级别分发（`code/src/channels/index.ts` 的 `accepts`）。升级后 56 张「在等你」用会话文件回放：等 5 分钟可少到 29 张，其中 18 张发出时用户前 10 分钟在别的会话打过字。

## 已拍板

- **等候间隔**（用户 2026-10-28 认同做法，值按协调方建议）：只用于「在等你」（含授权等待）。AI 停下后等 **5 分钟** 再判断要不要发；这期间用户在这个会话里有新的真人发言（或授权等待已被处理、会话继续往下走），就不发，**也不调用模型**。5 分钟到了仍没动静，再调模型判断并写快照、发卡。
- **判断在不在场**：发卡那一刻，最近 **10 分钟** 内用户在任何一个被盯的会话里有过真人发言，就算在场。信号只来自会话记录里已有的真人要求时间（`requestRefs` 等），不读系统空闲时间、不碰键盘屏幕（D21）。
- **在场时的出口**：只作用于「现在就要你」这一级。在场 → 只弹本机通知，不推飞书；不在场 → 照旧本机通知加飞书。「有空看」照旧只发飞书。发件记录照常写，并记下这张卡按在场 / 不在场走了哪个出口。
- **跑偏、loop 暂停、看不见了**：不等间隔，照常发；在场时同样只弹本机通知。
- **卡片逐件**：「要你做」拆成逐件，每件一句，打一个标签：回复会话 / 你去做 / 要你定·红线 / 不用管。有建议的附上建议（AI 自己在最后输出里给的建议优先）。标签由模型在原来那次判断调用里顺带给出，不多花调用；**红线由规则硬判**：涉及删除、合入、推到远端、对外发消息、花钱、授权的，不管模型怎么标都显示为「要你定·红线」。模型不可用时规则兜底，至少给出一件。
- **卡片分区**：上面「要你做」区（逐件 + 标签 + 建议）；下面「给 personal agent 的反馈」区（正确 / 误报 / 看不懂），默认收起。**不放输入框**（送达通道没就位前，不能让用户以为已经回了）。本机通知只写第一件和总件数。
- **影子对照的底子**：快照里存下逐件内容、标签、建议；之后检测到用户在该会话的下一句真人发言时，把这句（原文的引用或固定长度摘录，按现有「不复制真人要求正文」的做法取舍）记到这张卡的快照旁。本段只记录，不打分。
- 数据只追加；旧卡片、旧快照缺新字段照常读；升级后已发过的提醒不重发、不重新调模型。

## 验收标准

A1. 操作：构造一个 CC 会话停在问你问题，3 分钟后样本里追加一条你的回复；检测跑过 5 分钟
    预期：没有「在等你」提醒；这期间没有调用模型
A2. 操作：同 A1，但一直不回，所有会话里都没有你的发言；检测跑过 5 分钟
    预期：发出「在等你」，飞书（模拟）和本机通知都收到
A3. 操作：同 A2，但第 4 分钟你在另一个会话里发过一句话
    预期：只弹本机通知，飞书没有这张卡
A4. 操作：钩子报「等授权」，2 分钟内会话继续往下走了
    预期：不发提醒
A5. 操作：判断器替身给出三件要你做：一件回答问题（带建议）、一件要你去别处操作、一件是删除旧文件
    预期：卡片逐件列出，标签依次是「回复会话」「你去做」「要你定·红线」；第一件带建议；删除那件不管替身怎么标，都显示为红线
A6. 操作：查看 A5 那张卡片
    预期：分两区：「要你做」，和默认收起的「给 personal agent 的反馈」（正确 / 误报 / 看不懂）；没有输入框
A7. 操作：查看 A5 卡片的发件记录
    预期：快照里有逐件内容、标签、建议
A8. 操作：A5 之后，在样本会话里追加你的一句回复
    预期：快照里记下了你实际回的这句
A9. 操作：分别构造跑偏、loop 暂停
    预期：不等间隔，照常发出；在场时只弹本机通知
