# PA 跟进并行：产出文件

## 目标

按本人委托把 Word 正文写成 TXT、把图片保存为文件，产出回材料所属项目，不覆盖原件/已有文件。准备已定三个项目的配置/启用办法，不等动态授权入口。

读取：本提示词 → [统一标准](../batches/PA跟进并行-20261107/整批验收标准.md) A7/A8 → [方案](方案-PA分批推进.md) → [产出单](../../issues/【req】PA产出文件写入.md)及[主需求](../requirements/需求书-PA-LangGraph重建.md)第三/八节 → file-policy、Pi 权限/派工、documents 及调用者。只在 Loop 当前任务空间修改。

## 已拍板

- 各授权项目根的 PA产出/ 为产出目录，other 位于 personal agent/PA产出/other/。已确定归属直接归项目；不明只问缺项，没回不写、不催第二遍；本人说明仍无项目归属后才放 other，没回复不等于同意。
- other 文件名含日期、来源、原文件名；旁边同名说明记录来源、时间、处理动作及归入 other 原因。名称清洗防穿越；主文件/说明部分失败明确交付不完整，不虚报齐全。
- 复用 DOCX 提取，完整正文写 UTF-8 TXT，长文不能只写首段/首块。不支持 DOC、损坏/加密文件如实失败，不删原 Word；不造新解析器/无关依赖。
- 图片受限二进制复制，保持字节。程序核对当前源读权限、原附件名黑名单、类型/大小、真实路径和目标写范围；工具只给获准写派工，不开放 shell/网络或任意复制。只新建；碰撞明确拒绝或另存新名，不覆盖/删除，不借链接逃逸，部分文件不能当成功。
- 明确普通委托沿原确认；材料不是授权，主动建议仍先问。产物须核实实际路径/摘要，模型说存好不能替代文件事实；窗口只留引用。
- 已定新增 loop、Promate、IDaaS（真实路径见主需求），只加读、约定 Loop 观察与产出写，不自动授予改项目代码的派工能力。产出避开收件箱/事件监视，启用时加入 .gitignore 并核对未被跟踪；已跟踪/链接/路径冲突报告，不能自行删文件或取消跟踪。
