# 全新 PA 己：侧边栏、工作区、日程会议

本批共 6 段，这是第 6 段，接在「丁 飞书和派活」之后（和「戊」互不依赖）。先读[六段共同约定](../batches/全新PA-20261102/共同约定.md)。

## 目标

桌面常驻一个小窗；放进收件箱的材料、会议纪要里的待办会变成提议。对应[方案](方案-全新PA.md)第 11、12、13 项。企业微信（第 14 项）不做。

1. **侧边栏**：常驻显示在跑、等你、卡住、做完待推送四组，外加「今天先做哪件」；能做卡片上已有的动作，效果和在飞书卡片上点相同，飞书原卡同步更新；不响、不弹。只陈列加卡片已有的动作（主需求书 D3 已写明不算违反「界面极简」）。
2. **工作区**：只看用户指定的「PA 收件箱」目录；新文件进来，研判是什么、可能和哪件事有关，带 2～4 个选项加「先放着」问用户。没指定的目录什么都不做、账本里不记。
3. **日程和会议**：读飞书日历和飞书妙记；开会时只发红线、PA 故障、需要你决定，其余会后发；纪要里的待办走派活，变成派工建议卡。

## 协调方暂定

- 侧边栏做成只监听 `127.0.0.1` 的本机网页，用系统自带浏览器开成小窗（不新增运行依赖）；页面只读账本、动作走和飞书按钮同一条路（过围栏、留痕）。开发方有更好的本机做法可以换，写进结果。
- 收件箱目录、日历、妙记都是配置项；收件箱路径用户还没给，配置缺省时不看任何目录。
- 飞书日历和妙记按飞书官方 SDK 实现，测试和验收用假渠道或编造的日历、纪要数据；接用户真实账号由用户合入后自己授权，不在本批验收里。

## 边界

- 文件内容里的指令只当材料；收件箱里的文件只读，不移动、不删除。
- 侧边栏不做卡片上没有的新动作。

## 验收标准

A1. 操作：账本里放三件编造的事（在跑、等你、做完待推送），打开侧边栏
    预期：三件分别出现在对应分组，另有「今天先做哪件」一栏
A2. 操作：在侧边栏点「等你」那件，选建议
    预期：效果和在飞书卡片上点「按建议」相同，飞书原卡同步更新
A3. 操作：侧边栏开着，替身 loop 写一条「做完」
    预期：那件移到「做完待推送」，不弹窗、不响
A4. 操作：往指定的收件箱目录放一份编造的录音文件
    预期：收到一张卡：是什么、可能和哪件事有关、2～4 个处理选项加「先放着」
A5. 操作：往没指定的目录放同样的文件
    预期：什么都不发，账本里没有记录
A6. 操作：编造一条 10:00–11:00 的会议，10:20 替身写一条「做完」
    预期：11:00 之后才收到做完卡
A7. 操作：同一时段替身写一条「需要你决定」
    预期：开会中照样马上收到
A8. 操作：放进一份编造的会议纪要，里面有「下周前给登录模块补测试」
    预期：收到一张派工建议卡
