## 已拍板

- 感知原则：适配器只从各工具记录里取方案第 12 节表中的核心信号，表外的记录类型、字段一律忽略，不因为遇到不认识的东西报错或放弃整份文件。
- 「看不见了」只在两种情况下成立：来源目录整体读不了，或这个来源的核心信号整体取不到。单个文件读不了只影响这一份，其余会话照常判断和显示。
- 读不了的文件按来源合并成一条提醒：写数量，附不超过 3 个例子；单条提醒正文不超过 4 KB。
- 各工具「你本人说的话」按方案第 12 节认：Codex 取 `item_completed` 里的 `UserMessage`；Claude Code 没有 `origin` 的旧版本取文本型且不以 `<` 开头的；以 `<` 开头的、Pi 的 `custom_message`、任务通知都不算。
- Codex 子代理会话并入父会话，总览里不单独占一行。
- loop 只认「项目目录/<会话号>.md」形式的总结（可带 `claude-`、`codex-` 前缀），其他文件都不读；不跟随符号链接；没有读权限的文件跳过，不算看不见。总结缺「## 需要你做的事」这一段时，交代里写「总结里没写」，不写「没有待办」。
- 配置里可以写要忽略的项目目录前缀（如 `/private/tmp`、`/var/folders`），这些项目的会话不进总览、不发提醒。
- 所有输出（`--json`、数据目录里的每个文件）始终是合法 JSON：截断文本时不切断字符，表情等多字节字符完整保留或整个去掉。
- 没有新动静时重复检测，数据目录只增加很少的记录。
- 第一批的提醒分级、格式、状态规则全部不变。
