## 问题与影响

## 因果链

```
满盘 → 提醒一次，记下「已提醒」
  → 夹一轮非满盘失败（如 lock_busy）→ 外层把这轮当成功 → 清掉「已提醒」
  → 再次满盘 → 又提醒一次
```

## 处理方向

只有完整检测成功、日志也恢复时，才解除满盘提醒；补「满盘中夹锁忙」的回归。
