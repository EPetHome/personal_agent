# 点「正确」被当成出过的问题，触发了复盘卡片

状态：已修复、已核销（2026-10-27 合入 `b80df82`；用户 2026-10-27 点「正确」回「不会记成问题」，未再触发复盘）。修复见[提示词-反馈闭环与卡片](../../docs/prompt/xx/提示词-反馈闭环与卡片.md)。

## 问题与影响

【必须修改】用户在提醒上点「正确」，意思是「这事确实该叫我」，并不是出了问题。复盘却把它当成问题记录，算成「第 2 次」同类问题，推了一张复盘卡片，让用户确认归因和对策。用户越认真反馈，收到的无意义复盘越多。

## 事实

2026-10-27 07:10 用户连续点了 5 次「正确」（都已记下）。之后推了一张复盘卡片：

```
谁：personal agent 的 Claude Code，你反馈过的问题
出了什么事：personal agent 的 Claude Code：在等你：正确；谁：…（把整张旧卡片正文塞了进来）；第 2 次，上次今天凌晨 03:10；
为什么算同类：同种工具出现同样的问题事实，具体原因仍待确认；归因：归因未定（待确认）；建议对策：还没定
```

- 「出了什么事」里嵌了一整张旧卡片的正文。
- 来源：真机 `outbox.jsonl`、`feedback.jsonl`。

## 分层归因

- 产品实现：复盘收集问题时，没有区分「正确」（确认提醒有用）和「误报 / 漏了」（真出了问题）。
- 验证：复盘测试的样本只用了 loop 返修，没有用户点「正确」的情况。

## 处理方向

- 「正确」只作为提醒有用的证据，不进入问题记录，不触发复盘；只有「误报」「漏了」和 loop 返修进入复盘。
- 复盘卡片不嵌入旧卡片正文，只写一句这是什么问题。
